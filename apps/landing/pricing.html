Questions about the price

The short answers. If one is missing, open an issue on GitHub and it will be added here.

Is it really free?

Yes, during preview. There is no checkout, no card field, and no trial timer. Pull the image and run it.

What happens after the preview?

Self-hosted installs keep working. If a managed or paid edition appears, it will be announced with its price before any charge. Nothing on this site takes payment now.

Do I need Docker?

For the installer, yes: Docker Engine 24+ with Compose v2, and Python 3.8+. The app itself is one container. Azure Functions is the other supported runtime.

Where does the audit data live?

In the data directory you mount, or in your Blob Storage when configured. The maintainers do not receive it.

Can I use my own agent?

Yes. Any MCP client can connect with a tenant-bound key: Claude, Copilot, Cursor, or a harness you built. The key contains the tenant.

Does Comply make us compliant?

No. It keeps the requirement, the evidence, and the conclusion in one record. Your auditor decides whether that record is enough.
