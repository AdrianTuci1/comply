Support, without a ticket queue.

Install Comply, connect an agent, or open an issue on GitHub. The project is in preview; there is no support contract.

Install Comply.

Give your agent the prompt. It installs Comply on a server you control, waits for the health check, and leaves the first account for you.

  1. Give your agent the prompt. Any agent with terminal access can run it.
  2. It runs the installer. Docker Engine 24+ with Compose v2, and Python 3.8+.
  3. Open the URL and create the first account. The first account becomes the administrator. No account is created for you.

Prefer to run it yourself? The README lists the same steps.

Setup prompt 
Install Comply on this server.

Requirements: Docker Engine 24+ with Compose v2, and Python 3.8+.

Run:
curl -fsSLO https://raw.githubusercontent.com/AdrianTuci1/comply/main/easy-install.py
python3 easy-install.py deploy --sitename=comply.example.com

When it finishes, open the URL and create the first account. That account becomes the administrator. Do not create an account for me.

Connect an agent.

Create a tenant-bound key in Settings → MCP access and API keys. Paste the endpoint and the key into any MCP client. The tenant is encoded in the key, so one client cannot read another tenant's assessment.

The agent asks in the user's language. Scope, evidence summaries, and conclusions are stored in English, and the exported package is English.

Read the API and MCP reference

MCP client configuration 
{
  "mcpServers": {
    "comply": {
      "type": "http",
      "url": "https://comply.example.com/mcp",
      "headers": {
        "Authorization": "Bearer sk_mcp_<tenant>_<key>"
      }
    }
  }
}

Replace the host and the key with the values from your deployment.

What you should see.

After the first account, the workspace opens on the dashboard. The board, the public trust page, and the agent guide run in the same container.

Questions

Install, keys, logs, and the trust hostname.

The installer cannot reach the image.

The image is published at ghcr.io/adriantuci1/comply. Check that Docker can pull it anonymously, then run the installer again with --version latest.

I lost the administrator password.

Comply has no email recovery by default. If you still have another administrator account, use it to reset the account. If not, stop the container and use the users file in the data directory with the deployment's own recovery procedure. Keep a copy before you edit it.

Where are the logs?

docker compose logs -f comply. A healthy deployment answers /healthz with a JSON status.

Can I use a custom domain for the trust center?

Yes. Set the trust host when you install, or configure COMPLY_TRUST_HOST and point the DNS record at the same container.

Does Comply phone home?

The application does not send audit content to the maintainers. Content refresh reads the public source documents. The marketing site has no analytics.

Contact

For a bug or a question, open an issue in the public issue tracker. For a security problem, use the repository's private security advisory instead of a public issue.

Report a vulnerability privately

There is no support email or phone number during preview. GitHub is the place where reports are read.
